# Azentrix Budget Tracker

> Personal Finance Dashboard | [Live Demo](https://azentrix-fullstack-task1-delta.vercel.app)

## Features
### ✅ Required
- [x] Add, edit, delete income/expense entries
- [x] Category and date on each entry
- [x] Dashboard with monthly summary
- [x] Bar chart and category breakdown
- [x] Data persistence via localStorage
- [x] Fully responsive

### 🚀 Bonus
- [x] AI-style category auto-detection (O(1) keyword index)
- [x] Monthly budget goals with progress bars
- [x] CSV export and import
- [x] JSON backup export
- [x] Indian locale currency formatting (₹)

## Tech Stack
| Layer | Choice |
|---|---|
| Frontend | React 18 + TypeScript |
| Styling | Tailwind CSS v3 |
| Charts | Custom SVG + CSS |
| Storage | localStorage |
| Deploy | Vercel |

## Local Setup
```bash
git clone https://github.com/barkuntasrinivas2025-stack/azentrix-fullstack-task1
cd azentrix-fullstack-task1
npm install --legacy-peer-deps
```
